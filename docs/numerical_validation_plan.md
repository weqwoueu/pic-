# 论文数值验证执行计划

本计划以 `pdf材料/工作建议.pdf` 和 `pdf材料/3_plasma_expansion (12).pdf` 为准。当前只把已经验证过的 Maxwellian thermal-reservoir 路线投入计算；Kappa 和 Polytropic 必须先完成与初始分布一致的 thermal 边界采样，不能直接复用 Maxwellian 边界后当作正式结果。

## 当前基线

已完成的 `maxwellian_dx1_dt005_ppc1000_seed101_thermal` 是当前可复现的流程验证算例：

- `mi/me=400`，`Z=1`，`Te0/Ti0=100`
- `dx=dy=lambda_D0`，`dt=0.05/omega_pe`
- `omega_pi t=30/50` 对应 `it=12000/20000`
- `ppc=1000`，总初始宏粒子数 `1,024,000`
- `seed=101`
- `gamma_e(t30)=1.0443 +/- 0.0049`，`R^2=0.279`
- `gamma_e(t50)=1.0468 +/- 0.0058`，`R^2=0.164`

这组结果接近论文 Maxwellian 的 `gamma_e=1.023 +/- 0.003`，但粒子数远低于正式设置，只能证明计算、诊断、归档和后处理链路可用。

## 统一拟合规则

所有 case 使用同一规则：

```text
ln(Te/Te0) = (gamma_e - 1) ln(ne/ne0) + b
10^-3 <= ni/n0 < 1
```

每次拟合必须保存：

- 拟合时刻和空间范围
- 纳入及排除的数据点
- 斜率、截距、`gamma_e`
- `gamma_e` 标准误差、残差标准误差和 `R^2`
- 是否排除 Kappa 极端高能尾

`scripts/postprocess_maxwell_mi400.py` 已按该规则输出 CSV、散点拟合图和 `gamma_fit_included` 标记。

## 第一阶段：Maxwellian 验证

先串行执行，不要同时提交到同一个 `PIC-IFE_GEC` 工作目录。生成的 Slurm 脚本带有运行锁和自动归档。

当前 `1DPIC` 没有启用 MPI 或 OpenMP，运行阶段只申请 `1` 个 CPU 核。`cmake --build build -j4` 仅用于加速编译，不代表计算程序会使用 4 核。服务器按核计费时不要为单个 `1DPIC` 作业申请多余核心。

`ppc=1000` 冒烟测试的墙钟时间为 `58:51`，总 CPU 时间为 `58:32`，峰值内存为 `109588 KiB`。集群默认每核约分配 `7916 MiB`，1 核额度足以容纳下一组。按粒子数线性外推只是提交前的保守资源估算，不是性能结论：`ppc=20000` 约为 `20 h` 和 `2.1 GiB` 量级。下一组暂设 `36 h` 墙钟；实际完成后必须用 `sacct` 更新估算，再决定 `ppc=40000/80000` 的资源请求和是否需要显式增加内存。

`ppc=20000, seed=101` 已实测完成：单核墙钟 `11:04:17`，峰值内存 `2772 MiB`，最终粒子数误差 `dNe=2.14e-8`、`dNi=0`，能量预算误差 `dE=0.003364`。后处理得到 t30 `gamma_e=1.02191 +/- 0.00126`、`R^2=0.576`，t50 `gamma_e=1.02291 +/- 0.00129`、`R^2=0.457`。该结果与论文 Maxwellian 值非常接近，但仍需 `ppc=40000/80000` 与多 seed 证明收敛。

`ppc=40000, seed=101` 也已完成：单核墙钟 `20:50:36`，粒子数误差 `dNe=2.41e-8`、`dNi=0`，能量预算误差 `dE=0.001580`。后处理得到 t30 `gamma_e=1.02162 +/- 0.00090`、`R^2=0.710`，t50 `gamma_e=1.02087 +/- 0.00089`、`R^2=0.594`。相对 `ppc=20000`，t30 和 t50 的 `gamma_e` 分别变化约 `0.029%` 和 `0.199%`，拟合标准误差下降约 `1.40` 和 `1.46` 倍，接近粒子数翻倍时预期的 `sqrt(2)`。这构成良好的收敛趋势，但仍需 `ppc=80000` 最终点。

`ppc=40000` 实测峰值内存为 `5653604 KiB`，约 `5.39 GiB`。配置脚本现在以该作业为标定，根据 `初始总粒子数 x nt` 自动估算资源：内存增加 `35%` 余量并按 `500 MiB` 向上取整，墙钟增加 `50%` 余量并按 `12 h` 向上取整。对于 `ppc=80000, nt=20000, dx=1`，自动请求 `1 CPU`、`15000 MiB` 和 `72 h`。资源模型只用于防止任务因资源不足中断，每次完成后仍须用 `sacct` 保存实测值。

`ppc=80000, seed=101` 已完成，固定 seed 的粒子数收敛序列至此跑齐。作业墙钟为 `42:22:33`，峰值内存 `11284924 KiB`（约 `10.76 GiB`），粒子数误差 `dNe=6.14e-9`、`dNi=0`，能量预算误差 `dE=0.000606`（约 `0.061%`）。后处理得到 t30 `gamma_e=1.02282 +/- 0.00065`、`R^2=0.847`，t50 `gamma_e=1.02020 +/- 0.00068`、`R^2=0.700`。

相对 `ppc=40000`，80k 的 t30 和 t50 `gamma_e` 分别变化 `+0.118%` 和 `-0.065%`，仅为 `1.08` 和 `0.60` 个合并拟合标准误差；拟合标准误差分别继续缩小 `1.38` 和 `1.31` 倍。固定 seed 下可判定粒子数收敛通过。由于正式判据还要求 40k/80k 差异不大于 seed 样本标准差，下一步必须完成 `ppc=80000, seed=202/303` 后再给出最终统计误差条。

`ppc=80000, seed=202` 已完成并通过运行、守恒和后处理检查。t30 得到 `gamma_e=1.02019 +/- 0.00074`、`R^2=0.766`，t50 得到 `gamma_e=1.02080 +/- 0.00067`、`R^2=0.715`。相对 seed 101，t30/t50 分别变化 `-0.257%/+0.058%`；差异分别为 `2.66/0.62` 个合并拟合标准误差。t30 的结果说明单次回归标准误差不能代替跨 seed 的 PIC 统计误差。

仅用 seed 101/202 暂算，t30 的均值和样本标准差为 `1.02150` 和 `0.00186`，t50 为 `1.02050` 和 `0.00042`。两样本统计量只用于检查量级，不能作为论文最终误差条；完成 seed 303 后统一按三个 seed 等权计算均值、样本标准差和均值标准误差。

`ppc=80000, seed=303` 已完成。t30 得到 `gamma_e=1.02146 +/- 0.00065`、`R^2=0.824`，t50 得到 `gamma_e=1.01918 +/- 0.00064`、`R^2=0.703`。三个 seed 等权统计后，t30 为 `gamma_e=1.02149 +/- 0.00131`，t50 为 `gamma_e=1.02006 +/- 0.00082`，其中误差为跨 seed 样本标准差；均值标准误分别为 `0.00076/0.00047`。

40k seed 101 与 80k 三-seed 均值的差异在 t30/t50 分别为 `0.00012/0.00081`，仅占对应 seed 样本标准差的 `0.095/0.994` 倍。因此第一阶段的粒子数收敛判据正式通过。下一组为 `ppc=80000, seed=101, dt=0.025, nt=40000, dx=1.0` 的时间步收敛算例；配置脚本预计申请 `15000 MiB` 和 `5-12:00:00` 墙钟，实际运行时间预计约为当前基线的两倍。

## 单个 case 的配置命令

参数顺序为：`ppc nt boundary seed dt dx`。

```bash
cd ~/pic-
bash scripts/setup_maxwell_mi400_case.sh 20000 20000 thermal 101 0.05 1.0

cd PIC-IFE_GEC
module purge
module load intel/2022.1
module load cmake/3.23.5

rm -rf build
cmake -S . -B build -DCMAKE_Fortran_COMPILER="$(which ifort)"
cmake --build build -j4

sbatch run_maxwellian_dx1_dt005_ppc20000_seed101_thermal.slurm
```

作业成功后会自动归档到：

```text
verification_runs/maxwellian_dx1_dt005_ppc20000_seed101_thermal/
```

下载到本地后运行：

```powershell
python scripts\draw_png.py verification_runs\<case_name> 12000
python scripts\draw_png.py verification_runs\<case_name> 20000
python scripts\postprocess_maxwell_mi400.py verification_runs\<case_name>
```

时间步为 `0.025` 时，脚本会从配置中自动使用 `24000/40000`，后处理命令不需要手工指定步数。

## 第一阶段判定标准

- 同一 seed 重复运行时关键输出应一致；不同 seed 应产生不同统计实现。
- `gamma_e` 随 ppc 增加趋于稳定，噪声大致随 `1/sqrt(Nppc)` 下降。
- `ppc=40000` 与 `80000` 的差异应接近或小于随机种子样本标准差。
- `dx=1.0` 与 `0.5` 的 `gamma_e` 差异若超过约 2%-3%，需要继续检查网格依赖。
- `dt=0.05` 与 `0.025` 应比较 `gamma_e`、前沿位置、高能尾和能量预算。
- 所有正式 case 都必须具有能量预算和电子、离子粒子数预算。
