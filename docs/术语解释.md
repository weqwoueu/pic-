## 先记住五句话

1. 本项目研究一块等离子体向右侧真空膨胀时，电子速度分布如何影响电子温度、密度和离子前沿。
2. 三种电子分布的关键区别是高能电子有多少：Maxwellian 是普通热平衡分布，Kappa 有高能长尾，Polytropic 有有限速度截断。
3. 电子会先跑向真空并产生电场，这个自洽电场继续拉动离子，所以电子分布最终会改变离子膨胀。
4. 我们最关心的总结量是有效电子多方指数 `gamma_e`。它描述膨胀区内电子温度 `Te` 和电子密度 `ne` 怎样一起变化。
5. 在讨论三种分布谁快谁慢之前，必须先证明结果不依赖网格、时间步、粒子数和随机种子，并且能量与粒子数账目基本闭合。

## 一、整个研究在做什么

### 1. 物理场景

初始时，区域左侧有一块近似均匀、准中性的电子-离子等离子体，右侧是真空。开始计算以后：

1. 质量很小、速度很快的电子先向真空运动。
2. 电子和离子的空间位置短暂分离，形成自洽静电场。
3. 电场阻止更多电子逃逸，同时加速较重的离子。
4. 左侧出现向等离子体内部传播的稀疏波，右侧出现向真空移动的离子前沿。
5. 电子的速度分布决定有多少快电子能跑远，因此影响电场、温度演化和离子前沿位置。

程序虽然使用二维 `x-y` 网格，但主要物理沿 `x` 方向发生。`y` 方向采用周期边界，并对 `y` 做平均，所以论文展示的主要是随 `x` 变化的一维剖面。

### 2. 论文要回答的三个物理问题

| 问题 | 实际比较内容 | 想知道什么 |
|---|---|---|
| 电子分布效应 | Maxwellian、Kappa、Polytropic | 高能尾或速度截断怎样改变膨胀、温度和 `gamma_e` |
| 有限质量比效应 | 改变 `mi/me` | 电子惯性是否使 PIC 结果偏离无电子惯性的流体理论 |
| 边界条件效应 | thermal reservoir 与 specular reflection | 持续供热的长脉冲情形与停止供热后的短脉冲情形有何区别 |

### 3. 当前工作的逻辑顺序

```text
设定初始分布和边界
        ↓
PIC 推进粒子并求自洽电场
        ↓
输出密度、热速度、前沿、能量和粒子数
        ↓
检查守恒与数值收敛
        ↓
拟合有效 gamma_e
        ↓
比较分布、质量比和边界的物理差异
```

目前 Maxwellian 基线的诊断链路与数值收敛验证已经完成，正在进入 Kappa 和 Polytropic 的分布初始化及 thermal 边界实现核查；三种分布的正式物理比较还没有全部完成。

## 二、PIC 和数值计算术语

| 术语 | 英文 | 通俗解释 | 在本项目中的作用 |
|---|---|---|---|
| 粒子网格法 | Particle-in-Cell, PIC | 用有限数量的计算粒子代表大量真实粒子，同时在网格上计算电荷密度和电场 | 让电子和离子的非平衡速度分布能够直接演化 |
| 全动理学 | fully kinetic | 电子和离子都作为粒子推进，不预先假设它们始终满足 Maxwellian 或某条温度方程 | 可以观察高能尾、电子惯性和非平衡效应 |
| 宏粒子 | macro-particle | 一个计算粒子代表许多真实粒子 | 降低真实粒子数太大带来的计算量 |
| 粒子权重 | particle weight | 一个宏粒子代表的真实粒子数 | `Ne_domain` 等是带权后的数量，不等于内存中的宏粒子个数 |
| 网格单元 | cell | 空间离散后的小格子 | 电荷沉积、场求解和局部统计都在 cell 上进行 |
| 电荷沉积 | charge deposition | 把粒子携带的电荷分配到附近网格点 | 得到 Poisson 方程所需的电荷密度 |
| 推粒子 | particle push | 用电场根据牛顿方程更新粒子速度和位置 | 形成膨胀、逃逸和加速过程 |
| 自洽场 | self-consistent field | 场由当前粒子分布产生，场又反过来影响粒子 | 不是预先指定一个固定外电场 |
| Poisson 方程 | Poisson equation | 由电荷不平衡求静电势和电场的方程 | 连接电子-离子分离与离子加速 |
| Monte Carlo 采样 | Monte Carlo sampling | 用随机数从给定分布中生成粒子速度 | 初始化 Maxwellian、Kappa 或 Polytropic 粒子 |
| RMS | root mean square | 均方根统计 | 用速度涨落计算热速度和温度 |
| PIC 噪声 | particle noise | 有限宏粒子随机采样造成的统计波动 | `ppc` 越小，密度和温度曲线通常越抖 |
| 诊断 | diagnostics | 不改变主计算，只记录用于判断物理和数值质量的数据 | 本项目最近增加了全局能量和粒子数诊断 |
| 后处理 | post-processing | 计算结束后从原始输出提取剖面、拟合参数和图 | 生成 `gamma_e`、误差、`R^2` 和论文图 |

一个 PIC 时间步可以粗略理解为：

```text
粒子位置和速度
  -> 把电荷沉积到网格
  -> 解 Poisson 方程
  -> 得到电场
  -> 用电场更新粒子
  -> 处理边界和输出诊断
  -> 下一个时间步
```

## 三、物理符号对照表

### 1. 粒子、场和热力学量

| 符号 | 名称 | 含义 | 本项目怎样看 |
|---|---|---|---|
| `e` | 元电荷 | 单个质子电荷量的绝对值 | 电子电荷为 `-e`，单价离子电荷为 `+e` |
| `me` | 电子质量 | 电子惯性的尺度 | 很小，所以电子响应比离子快 |
| `mi` | 离子质量 | 离子惯性的尺度 | 基线使用 `mi/me=400` |
| `Z` | 离子电荷态 | 一个离子带多少个元电荷 | 当前标准 case 为 `Z=1` |
| `ne`, `ni` | 电子、离子数密度 | 单位体积内的粒子数 | 剖面通常画成 `ne/n0`、`ni/n0` |
| `ne0`, `ni0`, `n0` | 初始参考密度 | 未扰动等离子体的密度 | 基线为 `1.0e21 m^-3`，且 `ne0=Z ni0` |
| `rho` | 净电荷密度 | 电子与离子未完全抵消后剩下的电荷 | 反映电荷分离，准中性区应较小 |
| `Te`, `Ti` | 电子、离子温度 | 粒子随机热运动的能量尺度 | 本项目通过去除漂移后的热速度计算 |
| `Te0`, `Ti0` | 初始温度 | 温度归一化和初始化参数 | 基线 `Te0=1 eV`、`Ti0=0.01 eV` |
| `Pe` | 电子压强 | 电子密度和温度共同形成的压力 | 理想关系近似为 `Pe=ne kB Te` |
| `Phi` | 静电势 | 单位电荷具有的电势能尺度 | 空间梯度产生电场 |
| `E`, `Ex`, `Ey` | 电场 | 带电粒子受到电力的来源 | 主要关心膨胀方向 `Ex` |
| `vd` | 漂移速度 | 一个 cell 内粒子速度的平均值 | 表示整体流动，不等于温度 |
| `vth` | 热速度 | 粒子相对平均速度的 RMS 涨落 | `vth,e` 的平方与 `Te` 成正比 |
| `cs` | 离子声速 | 稀疏扰动向等离子体内部传播的典型速度 | 基本尺度约为 `sqrt(Z kB Te/mi)` |
| `xf(t)` | 离子前沿位置 | 最前方仍有足够离子密度的位置 | 用于比较膨胀有多快；当前画图以 `ni/n0>10^-3` 的最右点估计 |
| `kB` | Boltzmann 常数 | 温度与能量之间的换算常数 | 出现在热速度、Debye 长度和声速公式中 |
| `epsilon0` | 真空介电常数 | 真空对电场的响应常数 | 出现在 Poisson 方程和场能公式中 |

热速度使用本论文的约定：

$$
v_{th,e}=\sqrt{\frac{1}{N}\sum_j(v_j-v_d)^2},\qquad
\frac{T_e}{T_{e0}}=\left(\frac{v_{th,e}}{v_{th,e0}}\right)^2.
$$

注意：不同文献有时把热速度定义成 `sqrt(2 kB T/m)`。本项目采用论文中的 `sqrt(kB T/m)` 约定，比较数据时不能混用定义。

### 2. 特征尺度与归一化符号

| 符号 | 名称 | 公式或定义 | 直观理解 |
|---|---|---|---|
| `lambda_D0` | 初始电子 Debye 长度 | `sqrt(epsilon0 kB Te0 / (ne0 e^2))` | 电荷分离能明显存在的典型空间尺度 |
| `omega_pe` | 电子等离子体频率 | `sqrt(ne0 e^2 / (epsilon0 me))` | 电子集体振荡和响应的快时间尺度 |
| `omega_pi` | 离子等离子体频率 | `sqrt(ni0 Z^2 e^2 / (epsilon0 mi))` | 离子响应的慢时间尺度 |
| `vth,e0` | 初始电子热速度 | `sqrt(kB Te0/me)` | 速度归一化尺度 |
| `x/lambda_D0` | 归一化位置 | 实际长度除以 Debye 长度 | 图上 `x=100` 表示 `100 lambda_D0` |
| `t omega_pe` | 电子尺度时间 | 实际时间乘 `omega_pe` | 程序时间步采用这个尺度 |
| `omega_pi t` | 离子尺度时间 | 实际时间乘 `omega_pi` | 论文在 `30` 和 `50` 比较离子膨胀阶段 |
| `n/n0` | 归一化密度 | 当前密度除以初始密度 | 未扰动区约为 1，真空区趋近 0 |
| `e Phi/(kB Te0)` | 归一化电势 | 电势能除以初始电子热能 | 便于不同参数 case 直接比较 |

为什么要归一化：

- 等离子体变量跨越很多数量级，归一化后更适合数值计算。
- 图和结论不被某一组 SI 单位数字淹没。
- 不同密度、温度或质量比的 case 更容易在同一尺度上比较。

基线 `n0=1.0e21 m^-3`、`Te0=1 eV` 时，`lambda_D0` 约为 `2.35e-7 m`。因此：

| 归一化尺寸 | 约合实际尺寸 |
|---|---:|
| 计算域长度 `1024 lambda_D0` | `0.241 mm` |
| 初始 slab 长度 `128 lambda_D0` | `30.1 micrometer` |
| y 方向宽度 `4 lambda_D0` | `0.940 micrometer` |
| `omega_pi t=30` | 约 `336 ps` |
| `omega_pi t=50` | 约 `561 ps` |

这些 SI 数值只是帮助建立直觉。论文比较时仍以归一化量为主。

### 3. 数值参数

| 符号或字段 | 含义 | 为什么要改变它 |
|---|---|---|
| `Delta x`, `dx` | x 方向网格间距 | 检查空间分辨率是否足以解析 Debye 尺度和前沿 |
| `Delta y`, `dy` | y 方向网格间距 | 当前通常与 `dx` 相同 |
| `Delta t`, `dt` | 单个时间步长度 | 太大会造成推进误差或不稳定 |
| `it` | 当前步数 | 程序内部的离散时间编号 |
| `nt` | 总步数 | 决定任务最终运行到什么时刻 |
| `Nppc`, `ppc` | 每个 cell、每个物种的宏粒子数 | 越大统计噪声越小，但内存和时间显著增加 |
| `seed` | 随机种子 | 控制 Monte Carlo 初始采样；同 seed 应可复现，不同 seed 用于估计统计波动 |
| `stride` | 输出间隔 | 每隔多少步写一次诊断或剖面 |

基线中 `mi/me=400`、`Z=1`，因此 `omega_pe/omega_pi=20`。若 `Delta t omega_pe=0.05`：

$$
\omega_{pi}t = it\times 0.05/20.
$$

所以：

| `it` | `omega_pi t` |
|---:|---:|
| `12000` | `30` |
| `20000` | `50` |

若把时间步减为 `0.025/omega_pe`，达到相同物理时刻所需步数会翻倍为 `24000` 和 `40000`。

## 四、三种电子速度分布

### 1. 一张表先看懂

| 分布 | 速度空间外观 | 高能电子 | 理论 `gamma_e*` | 预期膨胀特征 |
|---|---|---|---:|---|
| Maxwellian | 中心高、两侧指数衰减的钟形 | 普通热平衡水平 | `1` | 近似等温，作为基准 |
| Kappa `kappa=2` | 中心类似 Maxwellian，但尾部衰减慢 | 很多，长尾很强 | `1/3` | 快电子跑得远，膨胀更快，可能出现密度越低温度越高 |
| Kappa `kappa=6` | 长尾较弱，更接近 Maxwellian | 中等 | `9/11约0.818` | 行为介于 `kappa=2` 与 Maxwellian 之间 |
| Polytropic `gamma=2` | 在有限最大速度处截断 | 没有无限高能长尾 | `2` | 膨胀时电子明显冷却，前沿通常较短 |
| Polytropic `gamma=3` | 截断处呈 step-like 阶跃 | 有严格速度上限 | `3` | 对速度离散和粒子噪声特别敏感，需要额外验证 |

### 2. Maxwellian 分布

Maxwellian 是热平衡粒子的经典速度分布。大多数粒子速度在平均值附近，速度越高的粒子越少，而且尾部按指数快速下降。

在本项目中它的作用是“正常基准”：理论上 `gamma_e=1`，表示膨胀区电子近似等温。如果 Maxwellian 都不能稳定得到接近 1 的结果，就不应急着解释更复杂的 Kappa 或 Polytropic 结果。

### 3. Kappa 分布

Kappa 分布的最大特点是 suprathermal tail，也就是超热高能长尾。相比 Maxwellian，它包含更多速度很大的电子。

- `kappa` 越小，高能尾越强。
- 必须满足 `kappa>3/2`，否则某些热力学矩可能不收敛。
- `kappa -> infinity` 时逐渐接近 Maxwellian。
- 本论文给出的理论联系为：

$$
\gamma_e^*=\frac{3-2\kappa}{1-2\kappa}.
$$

`kappa=2` 时理论 `gamma_e*=1/3`。因为它小于 1，在密度下降的膨胀区可能出现电子温度上升，这叫 inverted thermodynamics 或负温度-密度相关。它不表示温度是负数，而是表示 `ne` 越低时 `Te` 反而越高。

### 4. Polytropic 分布

Polytropic 分布与 Kappa 的方向相反：它不是增加高能尾，而是在某个最大速度处截断。因此没有任意高能的电子。

- `gamma_e>1` 时，密度下降通常伴随温度下降。
- `gamma=2` 是工作建议要求的代表性 case。
- `gamma=3` 时速度分布变成 step-like，截断非常陡。
- 陡峭截断在连续理论里可以定义得很清楚，但宏粒子和有限速度分辨率可能把边缘表示得不好，所以 `gamma=3` 需要专门做 `dx`、`dt` 和噪声敏感性验证。

### 5. 最容易混淆的两个 gamma

| 写法 | 含义 | 来源 |
|---|---|---|
| `gamma_e*` 或输入 `gamma` | 理论或初始化分布期望的多方指数 | 分布模型给定 |
| `gamma_e` 或 `gamma_e^PIC` | 从仿真输出的 `Te-ne` 关系拟合得到的有效指数 | PIC 结果测量 |
| `Delta gamma_e` | `gamma_e^PIC - gamma_e*` | 衡量 PIC 与理论的偏离 |

例如 Maxwellian 的理论值是 1，但当前固定 `seed=101` 的小粒子数 PIC 在 `omega_pi t=50` 拟合得到约 `1.0468`。这不表示初始化变成了 Polytropic 分布，而是表示有限质量比、边界、统计噪声和数值误差共同造成了一个小偏离。

本项目中的 `gamma_e` 是有效电子多方指数，不要简单等同于普通热力学课中理想气体的固定比热比 `Cp/Cv`。

### 6. 质量比研究中的 Delta gamma_e 和 beta

论文用下面的差值衡量 PIC 与无电子惯性理论之间的偏离：

$$
\Delta\gamma_e=\gamma_e^{PIC}-\gamma_e^*.
$$

- `Delta gamma_e=0`：PIC 与该分布的理论指数一致。
- `Delta gamma_e>0`：PIC 拟合指数高于理论值。
- `Delta gamma_e<0`：PIC 拟合指数低于理论值。

然后改变 `mi/me`，用类似下面的幂律描述偏离怎样变化：

$$
|\Delta\gamma_e|\propto (m_i/m_e)^\beta.
$$

`beta` 是质量比敏感性指数。`beta<0` 表示离子越重，偏离通常越小；`beta>0` 表示离子越重，偏离反而增大。它是跨多个质量比 case 拟合出来的量，不能从单个 `mi/me=400` case 得到。Polytropic `gamma=3` 在论文材料中呈不规则、非单调行为，因此不适合强行用一条漂亮幂律解释。

## 五、边界条件

### 1. 四个方向分别发生什么

| 边界 | 处理 | 物理含义 |
|---|---|---|
| 左 x 边界 thermal | 越界粒子按指定初始分布重新采样并射回区域 | 外部热源持续补充粒子热运动，近似 thermal reservoir |
| 左 x 边界 specular | 法向速度 `vx` 反号，速度大小不变 | 镜面反射，不从外部重新抽取热速度，近似能量守恒或准绝热 |
| 右 x 边界 outflow | 越界粒子删除 | 粒子进入真空并离开计算域 |
| y 边界 periodic | 从上边出去后从下边进入，反之亦然 | 模拟横向均匀、近似一维的膨胀 |

### 2. Thermal reservoir 与“全空间等温”不是一回事

Thermal reservoir 只表示左侧未扰动区持续与固定温度热库接触。膨胀前沿仍可能有明显温度变化，尤其是 Kappa 高能尾区域。

热边界的粒子不是简单从原分布随便抽一个速度，而应使用穿过边界的通量加权分布。更快的粒子更容易穿过边界，因此法向速度采样中会带一个速度权重。

### 3. 为什么三种分布要有各自的 thermal 边界采样

如果初始区用 Kappa 分布，但热边界仍不断注入 Maxwellian 粒子，长时间后系统会被边界悄悄改变，结果不能代表纯 Kappa case。Polytropic 也一样。

因此当前只把已核实的 Maxwellian thermal 路线作为正式计算入口。Kappa 和 Polytropic 必须先完成与各自初始分布一致的 thermal 边界采样，才能称为正式结果。

## 六、有效 gamma_e 是什么

### 1. 拟合关系

电子多方关系写成：

$$
\frac{T_e}{T_{e0}}=\left(\frac{n_e}{n_{e0}}\right)^{\gamma_e-1}.
$$

取对数后：

$$
\ln(T_e/T_{e0})=(\gamma_e-1)\ln(n_e/n_{e0})+b.
$$

在散点图中：

- 横轴是 `ln(ne/ne0)` 或等价的 `log10(ne/ne0)`。
- 纵轴是 `ln(Te/Te0)` 或等价的 `log10(Te/Te0)`。
- 直线斜率 `slope=gamma_e-1`。
- 因此 `gamma_e=slope+1`。
- 截距 `b` 吸收参考值和有限数据造成的小偏移，不是本文最主要的物理量。

换用自然对数或常用对数不会改变斜率和 `gamma_e`，但截距必须使用同一底数换算。

### 2. gamma_e 的物理直觉

假设从未扰动区向真空方向走时，密度在下降：

| `gamma_e` 范围 | `Te-ne` 关系 | 通俗解释 |
|---|---|---|
| `gamma_e=1` | `Te` 近似不随 `ne` 变化 | 近似等温，Maxwellian 基准 |
| `gamma_e>1` | `ne` 越低，`Te` 越低 | 膨胀冷却，Polytropic 型 |
| `gamma_e<1` | `ne` 越低，`Te` 反而越高 | 反常加热或倒置热力学，Kappa 高能尾型 |

### 3. 为什么固定使用 `10^-3 <= ni/n0 < 1`

这个区间由离子密度 `ni` 选择，但拟合的仍然是电子温度 `Te` 对电子密度 `ne`。

- 上限 `<1` 排除基本未受扰动、密度几乎恒定的初始区。
- 下限 `>=10^-3` 排除几乎没有离子的极前沿和纯噪声区。
- 使用 `ni` 定义区域可以避免 Kappa 快电子跑到离子前方后，把“只有少量快电子的尾区”误当成主体膨胀区。
- `kappa=2` 的极端高能尾若额外排除，必须在结果文件和论文里明确记录，不能只挑看起来顺眼的点。

### 4. 拟合输出怎么看

| 字段 | 含义 | 怎样解释 |
|---|---|---|
| `gamma_e` | 拟合得到的有效多方指数 | 最主要结果 |
| `slope` | 对数拟合斜率 | 等于 `gamma_e-1` |
| `intercept` | 拟合截距 `b` | 辅助量，不是主要结论 |
| `gamma_e_standard_error` | 单次线性拟合对 `gamma_e` 的标准误差 | 反映散点对该拟合斜率的约束程度 |
| `residual_standard_error` | 点到拟合线的典型离散程度 | 越小通常越好 |
| `R^2` | 直线解释数据变化的比例 | 越接近 1，幂律线性关系越清楚 |
| `n_points` | 纳入拟合的数据点数 | 太少时结果不稳定 |
| `excluded_points` | 因区间、无粒子或无效值被排除的点数 | 用于防止不透明地挑点 |
| `x_min`, `x_max` | 实际参与拟合的空间范围 | 证明拟合来自哪个膨胀区域 |
| `tail_exclusion` | 是否排除高能尾 | Kappa case 必须特别说明 |

`R^2` 低不一定表示程序错误。Maxwellian 的理论斜率接近 0，`Te` 本来变化就很小；如果 `ppc` 又低，随机温度波动可能比真实趋势更显眼，导致 `R^2` 很低。因此要同时看曲线、误差、`ppc` 收敛和不同 seed，而不能只看一个 `R^2`。

单次回归给出的标准误差还默认各数据点近似独立，而相邻 PIC cell 往往存在空间相关性。因此它主要是拟合质量指标，不代表已经包含网格误差、时间步误差、seed 波动和模型误差。正式不确定度仍要靠收敛测试与多 seed 统计补充。

### 5. 两种“误差”不要混为一谈

| 量 | 来自哪里 | 回答的问题 |
|---|---|---|
| 单次拟合标准误差 | 同一个 case 内的散点拟合 | 这一次拟合的斜率有多不确定 |
| seed 样本标准差 `sigma_gamma_e` | 多个不同随机种子得到的 `gamma_e` | PIC 随机采样使最终结论波动多大 |

工作建议要求正式结果写成：

$$
\bar{\gamma}_e \pm \sigma_{\gamma_e},
$$

其中平均值和样本标准差来自不同 seed。只有 3 个 seed 时可以报告均值和样本标准差，但不应过度宣称非常精确的 95% 置信区间；5 个 seed 会更稳妥。

## 七、全局诊断量和守恒账本

### 1. 为什么先做诊断模块

某张密度图看起来平滑，并不能证明计算正确。粒子可能在边界处理中凭空消失，能量也可能因为归一化或漏记边界交换而不守恒。诊断模块的作用是给计算记账。

`OUTPUT/global_diagnostics.csv` 每一行对应一个输出时刻，主要字段如下。

### 2. 粒子数相关字段

| 字段 | 含义 | 注意 |
|---|---|---|
| `Ne_domain` | 当前计算域内的带权真实电子数 | 不是宏电子个数 |
| `Ni_domain` | 当前计算域内的带权真实离子数 | 不是宏离子个数 |
| `Ne_lost`, `Ni_lost` | 从开放边界累计离开的电子、离子数 | 是从开始到当前时刻的累计值 |
| `Ne_injected`, `Ni_injected` | 粒子源真正新增的电子、离子数 | 当前 thermal 反射复用原宏粒子，因此它们可以保持为 0 |

粒子数相对误差定义为：

$$
\delta N_s(t)=\frac{N_s(t)+N_{s,lost}(t)-N_{s,inj}(t)-N_s(0)}{N_s(0)},
\qquad s=e,i.
$$

如果没有注入，直觉上就是“域内剩余 + 已经流失”应该等于初始总数。`delta Ns` 长期单向漂移，通常意味着边界计数、权重或粒子增删逻辑需要检查。

### 3. 能量相关字段

| 字段 | 含义 | 物理内容 |
|---|---|---|
| `Ke` | 域内电子总动能 | 包含电子整体漂移和随机热运动 |
| `Ki` | 域内离子总动能 | 可观察电场把能量转移给离子 |
| `Efield` | 域内静电场能 | 按 `epsilon0 E^2/2` 对网格积分 |
| `Einjected` | thermal 边界累计带入的能量 | 外部热库向系统供能 |
| `Elost` | 逃逸或边界处理累计带走的能量 | 离开计算域的能量 |
| `Ebalance_error` | 归一化能量预算残差 | 越接近 0 越好 |

域内能量定义为：

$$
E_{dom}(t)=K_e(t)+K_i(t)+E_{field}(t).
$$

能量预算残差为：

$$
\delta E(t)=
\frac{E_{dom}(t)+E_{lost}(t)-E_{inj}(t)-E_{dom}(0)}{E_{dom}(0)}.
$$

直觉上就是：

```text
现在域内的能量
+ 已经流出去的能量
- 外界后来注入的能量
- 初始能量
= 理想情况下接近 0
```

- `delta E>0` 表示账面上出现了能量盈余。
- `delta E<0` 表示账面上有能量缺口。
- 应重点看 `abs(delta E)` 的大小、随时间是否持续漂移，以及它是否随 `dt`、`dx` 和 `ppc` 改善。

本程序是二维笛卡尔模型，绝对总能量可理解为单位出平面厚度下的一致能量账本。论文数值验证最重要的是同一约定下的相对预算误差，而不是把该绝对值直接当成整个实验装置的总焦耳数。

### 4. 守恒不等于每一项不变化

电子动能下降、离子动能上升并不一定有问题，因为自洽电场可以在电子、离子和场之间转移能量。真正要检查的是把域内能量、流失和注入都算上以后，总账是否闭合。

Thermal reservoir 本来就允许外界与系统交换能量，因此不能只检查 `Ke+Ki+Efield` 是否恒定。Specular 情形更接近封闭能量反射，但右侧 outflow 仍会带走粒子和能量。

当前 thermal 左边界是把越界的同一个宏粒子重新采样后放回域内，所以粒子总数没有发生“删除再新增”，`Ne_injected` 和 `Ni_injected` 不一定增加。但诊断会把重采样前的能量记入 `Elost`，重采样后的能量记入 `Einjected`，从而记录热库与系统的净能量交换。

## 八、目标

### 1. 总目标

工作建议的核心不是“多跑几个 case”，而是建立一套别人可以复查的证据链：

```text
同一个物理结论
不因网格、时间步、粒子数和随机数明显改变
并且能量与粒子数账目合理
```

只有完成这一步，三种分布、质量比和边界之间的差异才有资格解释为物理效应。

### 2. 基线 case 要求

| 参数 | 建议值 | 用途 |
|---|---:|---|
| `mi/me` | `400` | 论文主基线，兼顾离子-电子尺度差和计算成本 |
| `Z` | `1` | 单价离子 |
| `Te0/Ti0` | `100` | 强调热电子主导的膨胀 |
| `Delta x=Delta y` | `1 lambda_D0` | 基准空间分辨率 |
| `Delta t` | `0.05/omega_pe` | 基准电子时间分辨率 |
| `Nppc` | `80000` 每 cell 每物种 | 论文级低噪声设置 |
| 输出时刻 | `omega_pi t=30,50` | 比较较早与较晚膨胀阶段 |
| 主要输出 | `ne, ni, vth,e, xf, gamma_e` | 描述密度、温度、膨胀速度和热力学关系 |

### 3. 网格收敛

比较：

```text
Delta x = 1.0 lambda_D0
Delta x = 0.5 lambda_D0
```

目的：确认主要结论不是网格太粗造成的。应比较 `gamma_e`、`xf`、密度和热速度剖面。若 `gamma_e` 差异超过约 `2%-3%`，需要继续检查网格依赖。

`dx` 减半后，x 和 y 方向 cell 都增加，初始宏粒子总数约增为 4 倍，所以该测试会特别吃内存。

### 4. 时间步收敛

比较：

```text
Delta t = 0.05/omega_pe
Delta t = 0.025/omega_pe
```

目的：确认粒子推进和电场耦合的时间离散足够细。应比较 `gamma_e`、`xf`、高能尾和 `delta E`。如果减小时间步后守恒和曲线明显改善，原时间步可能不够。

工作建议还提出：如果 Maxwellian 或 `kappa=2` 对 `0.025` 仍敏感，再补 `0.0125/omega_pe`。

### 5. 粒子数收敛

比较每 cell 每物种：

```text
Nppc = 20000, 40000, 80000
```

目的：区分真实物理趋势和 PIC 随机噪声。理想情况下噪声大致按 `1/sqrt(Nppc)` 下降；`40000` 与 `80000` 的 `gamma_e` 差异应接近或小于 seed 统计波动。

### 6. 随机种子误差

至少使用：

```text
seed = 101, 202, 303
```

最好再加 `404, 505`。目的不是让不同 seed 得到完全相同曲线，而是证明结论只发生合理的统计波动。最后报告不同 seed 的平均 `gamma_e` 和样本标准差。

### 7. step-like 专项验证

Polytropic `gamma=3` 的速度截断很陡，论文材料已经显示其 PIC 拟合值随时间偏离理论值。因此它不能只和其他 case 一样跑一次，而要专门比较网格、时间步和粒子噪声，并在论文中如实说明离散敏感性。

### 8. 每个正式 case 必须留下什么

| 类别 | 必需内容 |
|---|---|
| 配置 | 分布、边界、质量比、`dx`、`dt`、`ppc`、seed、总步数 |
| 可追溯性 | Git revision、作业号、节点、开始结束时间、退出状态 |
| 原始诊断 | `global_diagnostics.csv`、关键时刻场和速度文件、`run.log` |
| 拟合记录 | 时刻、空间范围、纳入和排除点、斜率、截距、`gamma_e`、标准误差、`R^2` |
| 特殊处理 | 是否排除 Kappa 极端尾，采用了什么阈值 |
| 结果图 | 剖面图、`Te-ne` 拟合图、能量预算、粒子数预算、收敛图 |

### 9. 工作建议最终想看到的图

1. `dx=1.0` 与 `0.5` 的 `gamma_e`、`xf` 和主要剖面对比。
2. `dt=0.05` 与 `0.025` 的对比。
3. `gamma_e` 随 `Nppc` 变化的粒子数收敛图。
4. 多个 seed 的 `gamma_e平均值 +/- 样本标准差`。
5. `Ke`、`Ki`、`Efield`、`Einjected`、`Elost` 和 `delta E(t)`。
6. 电子和离子的 `delta Ne(t)`、`delta Ni(t)`。
7. Maxwellian、`kappa=2`、Polytropic `gamma=2` 的统一比较。
8. Polytropic `gamma=3` 的 step-like 离散敏感性说明。

## 十、最近完成的工作到底有什么用

### 1. 全局诊断模块

新增 `DiagCounters.f90` 和 `GlobalDiagnostics.f90`，记录边界流失/注入的粒子与能量，并输出全局能量、粒子数预算。

用途：以前只能看到程序“跑完了”和剖面“像不像”；现在可以检查它有没有在数值上凭空造出或丢失粒子与能量。

### 2. 场能量计算修正

场能按物理电场和网格面积计算 `epsilon0 E^2/2` 的积分，而不是把归一化场直接当物理能量相加。

用途：避免 `Efield` 与粒子动能量纲不一致，导致能量预算完全失真。

### 3. 速度文件解析和列映射修复

Intel Fortran 会把较长的一条七列记录自动换行。后处理现在会把连续数值重新拼成七列，并正确识别漂移速度、热速度、粒子计数和 cell 编号。

用途：解决以前 `No numeric rows found`，同时避免列读错后画出“能运行但物理量错误”的图。

这里还有一个容易忽略的坐标规则：`OUTPUT_velocity.f90` 使用 `FLOOR(X)+1`，固定把完整 `[0,1024] lambda_D0` 域分成 1024 个速度统计箱。它的箱宽始终是 `1 lambda_D0`，不等于细化后的场网格间距。曾经把速度 cell 编号乘以 `dx=0.5`，使速度矩坐标错误缩短一半，并把 t50 `gamma_e` 从正确的 `1.0194` 误算成 `1.0886`。现在脚本从物理域和箱数计算坐标，并要求电子计数与场密度的对数相关系数至少为 `0.95`；本次细网格结果约为 `0.9997`。

### 4. 统一 gamma_e 拟合

后处理固定使用工作建议规定的 `10^-3 <= ni/n0 < 1`，并记录标准误差、`R^2`、空间范围、排除点和拟合图。

用途：防止不同 case 各自挑选有利区间，使三种分布之间可以公平比较。

### 5. 随机种子入口

增加 `PIC_RANDOM_SEED`，同时控制 Fortran intrinsic `RANDOM_NUMBER` 和旧的 `DRandom`。

用途：同一个 seed 可以复现；换 seed 可以测量 PIC 统计误差。服务器 Intel 编译以及 seed `101/202/303` 的独立运行已经确认该入口可用。

### 6. 参数化配置与自动归档

配置脚本现在接受：

```text
ppc nt boundary seed dt dx
```

作业成功后自动把配置、日志、诊断和关键时刻输出放到唯一 case 目录，并拒绝覆盖已有结果。

### 老师可能问的问题

**为什么不用真实质子质量比 `1836`，而用 `400`？**  
`400` 是论文基线，用于降低电子和离子时间尺度差带来的计算成本，同时保留明显的有限质量比效应。论文后续还会比较不同 `mi/me`，不能把 `400` 当成所有真实材料的唯一质量比。

**为什么粒子数要到每 cell 80000？**  
PIC 是 Monte Carlo 粒子统计，低粒子数会使局部温度尤其是稀薄前沿非常嘈杂。高 `ppc` 用于降低噪声并稳定 `gamma_e` 拟合。

**为什么选择 `omega_pi t=30` 和 `50`？**  
它们是以离子响应尺度衡量的两个膨胀阶段，可以观察结果是否随演化时间改变，而不是只看一个瞬间。

**`gamma_e` 越大是不是膨胀一定越快？**  
不能只凭 `gamma_e` 判断。它同时受高能尾、声速、电子冷却、边界供能和速度截断影响。应结合 `xf`、密度、热速度和能量分配一起解释。

**能量误差是不是必须精确等于零？**  
有限网格、有限时间步和宏粒子噪声下通常不会严格为零。要求是误差足够小、没有不可解释的持续漂移，并且在减小 `dt`、`dx` 或提高 `ppc` 后趋于稳定或改善。

**为什么 Maxwellian 的 `R^2` 很低但 `gamma_e` 接近 1？**  
因为 Maxwellian 的理论温度变化非常小，拟合直线几乎水平。低粒子数下的随机散点可能大于这条很弱的趋势，所以斜率仍接近 0，但 `R^2` 不高。正式结论必须通过提高 `ppc` 和多 seed 检查。

## 十五、阅读结果时的检查顺序

拿到一个新 case 后，不要先盯着 `gamma_e`。按下面顺序检查：

1. `run.log` 是否出现正常结束，是否有 NaN、崩溃或求解器异常。
2. `case_config.txt` 是否真的是目标分布、边界、`ppc`、seed、`dx` 和 `dt`。
3. `global_diagnostics.csv` 的粒子数和能量预算是否合理。
4. 密度、热速度剖面是否连续，前沿是否位于计算域内部。
5. 局部 `electron_count` 是否足够，稀薄区是否被噪声主导。
6. `gamma_fit_*.png` 中纳入和排除的点是否符合固定规则。
7. 再读取 `gamma_e`、标准误差和 `R^2`。
8. 最后与其他 `ppc`、seed、`dt`、`dx` 或物理 case 比较。

这个顺序可以避免把一个数值流程问题误讲成新的物理现象。
